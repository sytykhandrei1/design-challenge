## Композиция и вход

Amanecer, Jacarandá, Cenote, Noche используют одну композицию. Спереди — официальный PLATA, выбранный пользователем знак облака и Mastercard. Чипа, имени, номера, срока, CVV нет. Сзади — только тёмная палитра соответствующего дизайна. Надписи `Details hidden` также нет.

Удалены `PlataDigitalDetails`, генератор credentials, `updateDetails`, отдельная задача обновления данных, данные в accessibilityValue и редактор в demo. Отдельные `name()` / `nameRect` в Artwork сохранены как переиспользуемая типографика физических Plastic и самим Digital не вызываются. Соседняя задача синхронно убрала поля имени/номера в продуктовом setup и передачу details в renderer.

Основная галерея: Account → плюс → Me → Digital. Demo: Account → Transfer → Digital. Debug-аргументы `--plata-metal-v1-demo --plata-digital-default`. Preview: `PLATA Digital — four light studies`.

Front / Light / Back / Edge выбирают ракурс. Один палец вращает X/Y; pinch увеличивает 1…3×; двойной тап сбрасывает масштаб. Выбор цвета сохраняет позу и масштаб. Studio / Soft / Night меняют освещение.

## Материалы и ресурсы

Target `Plata`, iOS 18.0+, SwiftUI + non-AR RealityKit. Стандартный `PhysicallyBasedMaterial`, без CustomMaterial, .metal, AR session, camera permission и внешних зависимостей. Замкнутая геометрия 85.60 × 53.98 × 0.76 мм, скругление 3.18 мм; back повёрнут на 180° вокруг Y без отрицательного масштаба.

| Область | Metallic | Roughness | Specular | Clearcoat / roughness | Emission |
| --- | ---: | ---: | ---: | --- | ---: |
| Front | 0 | 0.23 | 0.32 | 0.40 / 0.22 | 0.42 |
| Back | 0 | 0.55 | 0.16 | 0.12 / 0.40 | 0.30 |
| Edge | 0 | 0.32 | default | 0.65 / 0.18 | 0 |
| Облако | 0 | 0.40 | 0 | 0 | 0.20 |

PLATA/Mastercard сохраняют свои материалы печати со specular 0.20. Emission берётся только из artwork, постоянный emissiveColor чёрный. На гладком Digital нет normal/height maps; используются геометрические нормали. Физическая рефракция не симулируется.

Front/back растрируются из Swift в 3072×1937, PLATA — 3264×544, Mastercard — 512×320, cloud — 384×288. Это реальные растеризации в целевом разрешении, без апскейла. Цвет загружается как `.color`, маска из той же разметки как линейная `.raw`; namespace `plata_digital_v1/`. Имя и реквизиты больше не создают растры/маски/GPU-текстуры. HDR — неизменённый `plata_metal_v1/plata_studio.hdr` из raw bundle folder.

Загрузка/кэширование для основной галереи затем оптимизируется соседней задачей без изменения этой композиции и разрешений. Ей последовательно переданы Material/Coordinator после завершения проверок удаления данных. Результаты performance-проверок фиксируются в её отчёте, а не приписываются этому тесту.
