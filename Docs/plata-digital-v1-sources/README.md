# Исходник PLATA для Digital

Оригинальный белый SVG из пользовательского архива `01_Plata_Logo.zip`:
`01_Plata_Logo/01_Plata_Logo_Screen(RGB)/SVG/White/01_Plata_logo_white.svg`.

Архив найден среди вложений ранее предоставленной задачи «Прочитать контекст и задать вопросы» (6aae8820-8334-83e9-8777-558e3fe912b5). SVG сохранён байт-в-байт.

SHA-256: `db25252e6ed3f6cb48d9d47fae38a5bce7dc209c7ba63e5ba3c58171f00a9e89`.

В `PlataDigitalArtwork.logo()` напрямую перенесены все 77 команды пяти SVG-путей, включая координаты Bézier и правило even-odd для P. ViewBox 320×48; растр контура 3200×480, с масштабом ровно 10. Итоговая текстура 3264×544 включает прозрачное поле 32 px со всех сторон, чтобы граничные тексели не давали шов при наклоне; размер знака на карте при этом не меняется. Геометрия слоя на карте сохраняет отношение 320:48. Это преобразование в Core Graphics, а не реконструкция по изображению или набор шрифтом.

SVG хранится как источник в Docs, в runtime используются сгенерированные цветовой слой и маска из того же контура. Другие исходные PNG/HDR и реконструкция в `CardMaterials/v1` не изменены. Наличие оригинала логотипа не означает утверждения всей композиции/цветов Digital.

Размещение вордмарка соответствует общей композиции Metal из `manifest.json`: x=5, y=0, width=2038 на ширине 2048. Высота вычисляется из физических пропорций SVG, без растяжения. Брендовые промо из `Debito_card.zip` и `Credito_card-20260919T133711Z-1-001.zip` подтверждают размещение вдоль верхнего края. Видимость маски ограничена физическим скруглённым контуром карты; контуры букв внутри него не перерисовываются.
